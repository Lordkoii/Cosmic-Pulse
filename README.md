# COSMIC PULSE
## Star Citizen Performance Intelligence

Cosmic Pulse is a Windows companion application being built to help Star Citizen players understand **why the game is performing poorly, what is limiting their system, and whether a change actually improves the experience**.

The project is currently in **private alpha development**. Public downloads will appear here only after a build has been tested and is ready for distribution.

## Planned focus

- Star Citizen performance telemetry
- CPU / GPU / memory bottleneck analysis
- frame-time and 1% low analysis
- evidence-based optimization recommendations
- before/after performance comparisons
- crash and stability diagnostics
- session history and patch-to-patch comparisons

## Current status

**v0.1.0-alpha.0 is under private development.**

There is no public release available yet.

## Safety approach

Cosmic Pulse is designed as an external companion. The project does not intend to inject DLLs into Star Citizen, read game-process memory, intercept game/network traffic, automate gameplay, or modify the game client.
